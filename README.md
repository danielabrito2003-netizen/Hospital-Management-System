# Hospital Management System

Academic project developed as part of the **Object-Oriented Programming (OOP)** course of the Computer Systems Engineering degree.

## 📌 About the Project

Hospital Management System is a C# application designed to manage different entities and operations within a hospital environment.

The project was developed to apply Object-Oriented Programming concepts and to organize the application into separate layers for business objects, data management, and business logic.

## ✨ Features

- Patient management
- Doctor management
- Nurse management
- Staff and employee management
- Consultation management
- Medical examination management
- Diagnosis management
- Hospital information management
- Hospital bed management

## 🛠 Technologies

- C#
- .NET
- Object-Oriented Programming (OOP)
- Visual Studio

## 🧩 OOP Concepts

The project applies several Object-Oriented Programming principles and concepts, including:

- Classes and objects
- Encapsulation
- Inheritance
- Abstraction
- Exception handling
- Modular code organization

## 🏗 Project Structure

The solution is organized into different projects and layers:

- `ObjetosNegocio` — Domain entities and business objects
- `Dados` — Data management
- `RegrasNegocio` — Business logic
- `GereHospital` — Application entry point and interaction with the system
